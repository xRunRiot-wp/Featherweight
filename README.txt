Featherweight - lighter skins and stages for Melee doubles and teams
============================================================

Custom Melee skins and stages can be too big for Melee's memory when a doubles or teams match loads, so the game
freezes on the loading screen. Featherweight makes them lighter: it shrinks oversized images and stores 3D models
more compactly. Bones, weights and animations are never changed.

How to use
- Run Featherweight.exe (no install needed, Windows 10/11 64-bit).
- The first time, Windows may say "Windows protected your PC" (unknown publisher), because Featherweight is a free
  program without a paid signing certificate. Press "More info", then "Run anyway".
- Drop in a Melee ISO, one or more skin .dat files, or a folder of skins.
- Pick Cleanup, Solid (recommended) or Aggressive, check the before/after previews, and press "Make lighter copy".
- It always saves a NEW copy. Your original ISO or skins are never changed.

Updates
- Featherweight checks once a day for a newer version and offers "Update now" (turn it off in About).
- Or download the newest version from https://github.com/xRunRiot-wp/Featherweight/releases

Problems
- Press "Report a problem" in the program. It shows the whole report before anything is copied, and nothing is sent
  automatically. Reports go to https://github.com/xRunRiot-wp/Featherweight/issues (public, so leave out anything private).
